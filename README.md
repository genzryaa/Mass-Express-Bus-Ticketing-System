MASS EXPRESS — Online Bus Ticketing System

Online Bus Ticketing System built in Visual Basic.NET (Windows Forms). Designed to streamline long-distance express bus reservations in Malaysia, allowing passengers to register accounts, search intercity routes, pick available seats visually, print digital receipts, and manage their user profiles without queuing at physical station counters.

✨ Key Features

User Authentication & Registration (LoginForm1 & SignUpForm):

Secure login validation with masked password entry.

New passenger registration storing username, phone number, and password.

Route & Schedule Search (MainForm):

Select origin and destination terminals (e.g., TBS, Kota Bharu, Kuantan, Penang, Johor Bahru).

Travel date selection via DateTimePicker with automatic route fare calculation.

Top navigation strip for Home, About, Setting (Profile), and Logout.

Interactive Visual Seat Selection (SeatForm):

Live color-coded seat availability map (Red = Booked, White = Available, Green = Selected).

Prevents double-booking on the same route and travel date.

Passenger name and contact number entry prior to ticket confirmation.

Digital E-Ticket & Receipt Printing (InfoForm):

Displays full booking summary (Passenger Name, Phone No, Origin, Destination, Seat No, and Fare in RM).

Built-in Print Preview & Receipt Printing powered by PrintDocument and PrintPreviewDialog.

Account & Profile Management (ProfileForm):

Reset Password: Verify existing credentials to update account passwords.

Delete Account: Permanently remove a user profile from the system.

🛠️ Tech Stack

Language: Visual Basic .NET (VB.NET)

Framework: .NET Framework (Windows Forms)

IDE: Microsoft Visual Studio

Printing: System.Drawing.Printing (PrintDocument, PrintPreviewDialog)
